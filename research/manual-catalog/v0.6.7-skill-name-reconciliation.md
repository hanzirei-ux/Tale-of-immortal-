# Tale of Immortal — v0.6.7 Base Skill Name Reconciliation

**Date:** 2026-11-01  
**Status:** read-only localization research. No DEX, APK, native library, or existing Mod Menu gameplay function changed. Rarity is intentionally excluded.

## Main result

The game's English `global-metadata.dat` contains localized skill descriptions where a **skill name and a numeric parameter BaseID appear together**. Checking these IDs against the native `ConfBattleSkillBase` catalog and verifying spelling/categories against external Tale of Immortal community references produced:

- **30 direct in-game name/BaseID pairs**.
- **2 additional lexical matches** where a projectile/attack name rather than the literal skill name accompanies a BaseID (`Firebolt 41111`, `Voltshot 43111`). These are lower-confidence.
- In the prior inventory example of **183 actual manual instances** aggregated to 102 Type/BaseID/Grade rows, **40 instances** have a directly mapped base-skill name; **2** are lexical inference; **141** are still unmapped.
- **10 other community names** were listed without BaseIDs; **9/10** are found as exact English strings in the analyzed game metadata. No fabricated IDs were assigned.

This is **base-skill naming, not the full final manual display name**. The full book name may depend on a generated prefix/name-selector. Manual Level is also not determined by Grade alone.

## Localization discrepancies and conditional inferences

- In-game English is **Crackling Jade Spear** for BaseID 23111, while the community Spear page currently uses **Cracking Jade Spear**. Keep the game file as canonical for this binary and the wiki name as a searchable alias.
- Community Sword documentation associates **Sunset Sword** with the Rain of Swords attack. The in-game description references Rain of Swords with ID **24114**, but does not provide a direct name+ID pairing. Thus `24114 → Sunset Sword` is **only a candidate**, not committed as a verified row.
- Other names including Fire Flare, Fierce Fire, Scorching Eruption, Firerider, Crescent Blade, Spiritual Water and Illusion remain unlinked pending proof.
