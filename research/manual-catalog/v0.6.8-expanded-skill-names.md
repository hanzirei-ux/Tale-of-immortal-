## Evidence and reliability

- Each new BaseID is present in the extracted native `ConfBattleSkillBase` / `ConfBattleAbilityBase` reference list.
- Each new name appears in the exact same in-game English localization phrase as `&<BaseID>_<parameter>&`, using either duplicated `NameName's property` entries in the sorted metadata string heap or a direct battle description (e.g. `Each Sweeping Wind deals &54116_dmg&`).
- The local verification artifact includes the exact string and **zero-based byte offset** for all 32 additions; metadata SHA-256 `9be3762476a87e8be23e3fa589b44f084027a5c7f1ff78b9be5f013fb5d131b3`.
- English names and school categories were checked against relevant wiki pages. The game-localized string is authoritative for this analyzed build when versions disagree; community names are supplementary.
- **Quarantine ambiguous terms instead of assigning potentially wrong IDs:** Firebolt (41111 vs 41112), Icy Aura/Frost Blast (52111), Meteor/Meteorfall (55112), and Dashing Lightning (53111 vs 53112). A skill's description may refer to another skill's parameter or an effect object, so a co-reference is not automatically the displayed book's identity.
