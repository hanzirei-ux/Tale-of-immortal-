# Tale of Immortal Android — v0.7.0 Ability `81001` name-selector audit

**2026-11-01 | Read-only research.** No APK, DEX, native library, save or working Mod Menu feature was changed. Rarity excluded.

## Main finding

The 183 decoded inventory manual instances include **80** with `MartialType=4, BaseID=81001`. Their complete per-instance grade, prefix ID sequence and raw prefix-value sequence are **all different**.

| Measure | Verified |
|---|---:|
| Ability `81001` instances | 80 |
| Distinct ordered prefix-ID vectors | 79 |
| Distinct complete ID + raw-value vectors | 80 |
| Total prefix slots within these instances | 532 |
| Different numeric prefix IDs used | 27 |
| Per-instance prefix-count range | 4–9 |
| Grade range observed in this save | 2–9 |
| Independently verified final names | 0 |
| Independently verified display Levels | 0 |

Two instances have the exact same prefix-ID vector `[1,1,1,1,26]` and Grade 2, but different underlying raw prefix values. **Do not collapse them into one manual or assume their rendered title is identical**. Equally, 80 distinct instances **do not guarantee 80 distinct display names** because the game's name selector can produce collisions.

## Direct ARM64 evidence for name selection

Build SHA-256: `c477a5637b89f78ca449ff65ad4c9137296ba680923b602db50831ecb5901099`.

- `SkillInfoData.GetName` at `0x5840ed4` reaches `ConfBattleSkillPrefixName.GetName` at `0x52c0d28` via calls at `0x5840fd4` and `0x5841054` on specific branches.
- `0x52c0e2c` calls `GetTotalValue` with parameter `3`; `0x52c0e3c` calls it with parameter `5`.
- The first result is multiplied by **123** (`0x52c0e84`) and reduced with signed divide/remainder by the first list length (`0x52c0ea0–0x52c0eac`).
- The second result is multiplied by **456** (`0x52c0eb8`) and reduced by the second list length (`0x52c0ed8–0x52c0ee0`).
- A subsequent comparison path can change the second seed with bitwise `OR 1` (`0x52c0f04`) and repeat selection.
- v0.6.0 recovered **200 localized name parts in each group**. Because `gcd(456,200)=8`, the normal second selector has **25 possible index residues** (multiples of 8); the conditional alternate can reach another 25 residues. This is a mathematical property of the disassembled indexing branch, **not proof of which suffixes occur in actual manuals**.

**Blocking uncertainty:** `GetTotalValue` iterates runtime prefix data and calls virtual getters. The values for groups 3 and 5 **have not been reconstructed from save**. Using `prefixID`, Grade or the two constants as direct substitutes would fabricate names. Nor is it proven that all 80 instances execute the same branch or render distinct titles.

The Level code likewise passes three separately sourced arguments through `SkillInfoData.GetLevel` to `ConfBattleSkillLevel.GetLevel`; **Grade != proven display Level**.

- `output/ability_81001_aggregate_report.json`: statistics, no identity data.

The original proprietary binary, metadata, full user save and per-instance profile fingerprints are **not uploaded to this public repository**.
