# Tale of Immortal — v0.7.1 `GetTotalValue` field and loop trace

**2026-11-01. Read-only investigation.** No APK, DEX, JNI4, game binaries, user saves, or working Mod Menu features changed. Rarity deliberately omitted.

## Verified result

The original `libil2cpp.so` ARM64 implementation provides a more precise path for reconstructing generated manual names. The two branches in `ConfBattleSkillPrefixName.GetName` invoke `GetTotalValue` with group arguments **3** and **5**, respectively; they are **not directly obtained by summing saved prefix IDs, Grade, or raw prefix-level slots**.

| ARM64 VA | Verified instruction / meaning |
|---|---|
| `0x52c0e28`, `0x52c0e2c` | `w2=3` followed by call to `GetTotalValue` at `0x52c0f78` |
| `0x52c0e34`, `0x52c0e3c` | `w2=5` and same call |
| `0x52c1024`, `0x52c1040` | Read manual source data and cached prefix collection |
| `0x52c1144` | Read prefix configuration member at offset `+0x18` |
| `0x52c11d0` | Read prefix configuration member at offset `+0x20` |
| `0x52c127c`, `0x52c1398` | Read prefix configuration member at offset `+0x28` |
| `0x52c1074`, `0x52c1288` | Prefix/config number contributes with multiplier **123** |
| `0x52c139c`, `0x52c13a8` | Second loop uses multiplier **prefix position + 2** |
| `0x52c120c`, `0x52c12a0` | Append formatted values via a string concatenation helper |
| `0x52c1404`–`0x52c146c` | Access text characters, apply numeric conversion helper and absolute value, accumulate final integer |

**Cross-check to metadata and constructor:** `ConfBattleSkillPrefixValueItem` fields are declared in the order `skillType`, `skillID` (integer array), and `number`. In the native constructor at `0x28336b4`, `0x28336b8`, `0x28336c8`, their offsets are respectively `+0x18`, `+0x20`, and `+0x28`. Those are the same offsets accessed through the prefix config object by `GetTotalValue`.

This confirms that **the previously recovered prefix configuration rows (v0.6.6) are used in the name-selector computation** and gives the two numeric weighting stages.

## Remaining blockers and interpretation limits

- An indirect virtual call involving the `skillID` array is not fully resolved; its exact text representation is unknown.
- The numeric conversion helper's behavior for non-digit characters and locale variations is not fully established.
- Neither `GetTotalValue(3)` nor `GetTotalValue(5)` has been calculated for any actual save instance.
- **0 final manual names and 0 display Levels are verified for the 183 saved examples.** The 80 Ability examples with base ID `81001` must not be assigned fabricated titles.
- This is a **static-call-graph finding**, not an Android runtime hook or an installable DEX patch. DEX v0.3.6 remains untouched.
