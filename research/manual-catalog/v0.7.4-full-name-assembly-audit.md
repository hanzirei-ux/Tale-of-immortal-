# Tale of Immortal Android — v0.7.4: Full manual name assembly (conditional)

**2026-11-01 · Read-only reverse-engineering research.** No APK, DEX, native binary, save or working Mod Menu feature was modified. Rarity intentionally excluded.

## New static evidence

The earlier v0.7.3 output contains **two selected prefix-name components**, not the full displayed manual title. We verified the assembly in `SkillInfoData.GetName` at `0x5840ed4`:

1. Calls `ConfBattleSkillPrefixName.GetName` at `0x52c0d28` (sites `0x5840fd4` and `0x5841054`).
2. Retrieves a separate base-name/key field at `+0x18` (`0x5840f40`) and passes it to localization helper `0x456a018`.
3. For locale-selector outcomes **2 or 3**, the code at `0x5841018` concatenates **selected prefix + literal space + localized base name** through a three-string helper `0x7566fe0`. Other selector outcomes join prefix and base name directly with `0x755dc8c` (`0x5841094`).
4. The space is an actual game metadata literal: `0x7f7c9f0` GOT -> `0x856c930` relocation -> `0xa000016f` metadata token -> string index **183**, equal to `" "`. The precise human language labels of locale values 2/3 remain to be verified; this establishes their branching behavior only.
5. The collision path in `GetName` at `0x52c0ef8` compares selected parts and, if equal, uses `OR 1` on the second seed at `0x52c0f04` before reselecting.
