# Tale of Immortal Android — v0.7.8 Native Name Localization Key Recovery

**Date:** 2026-11-01. **Read-only research only.** No APK, DEX, JNI4, native binary, game save, or existing Mod Menu v0.3.6 cheat was changed. Rarity excluded.

## Breakthrough

The previous v0.7.7 cross-audit joined the 183 saved manual instances to *conditional* title and static Level predictions, but only 49 instances had directly evidenced English base-skill names. We have now found the native **localization key for all 183 sample instances**, by analyzing the actual name argument passed into the game's configuration item constructors—not by guessing wiki names.

The relevant constructors each take a string in ARM64 register **`x2`**, which they store to their respective IL2CPP instance's **`name` field at offset `+0x18`**:

- `ConfBattleSkillAttackItem..ctor` at `0x5d4eccc`, store `0x5d4ed44`;
- `ConfBattleAbilityBaseItem..ctor` at `0x5a7c82c`, store `0x5a7c894`;
- `ConfBattleStepBaseItem..ctor` at `0x2869904`, store `0x2869974`.

Each constructor call's `x2` was traced through **ARM64 ADRP/LDR → relocated GOT entry → static IL2CPP tagged string literal → string-literal table in `global-metadata.dat`**. The script checks both original file hashes and discards the literal `0` sentinel as a non-name.
