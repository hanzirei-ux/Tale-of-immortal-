# Tale of Immortal Android — v0.8.3: Complete static decoding of compiled localization records

**2026-11-01 | Read-only static research.** No APK, DEX, native SO, save, or Mod Menu v0.3.6 feature changed. This report is aggregate-only for the public repository.

## Result and provenance

The matching original Android `libil2cpp.so` and `global-metadata.dat` are SHA-256 pinned against the previously verified baseline. All **56,259 / 56,259** compiled `GameConfPack2.dll / ConfLocalTextItem2` records now have the **five text-field pointers statically decoded**: key, Chinese, Traditional Chinese, English, Korean. This **does not mean** that all values are nonempty or translated to English; some source strings are empty by design, and several English fields contain Chinese characters.

The final **17** previously undecoded values were recovered: **14** from register-preserving `LSR #0` / `ROR #0` aliases and **3** from compiler-generated branch-island GOT loads, whose short branches return to the next original instruction. No IDs, localization keys, constructor locations or already-decoded fields changed from v0.8.2.

**Offline tests:** 22/22 PASS. Zero runtime/UI confirmations are claimed.
