# Tale of Immortal Android — v0.8.4 Native constructor evidence for six missing localization keys

**2026-11-01 | Static, read-only audit.** No game APK, DEX, SO, save, or existing v0.3.6 Mod Menu functionality was modified.

## Finding

The six `name` localization keys absent from the 56,259-row compiled `GameConfPack2.dll/ConfLocalTextItem2` dictionary are present as **actual name arguments to native manual configuration constructors**. The verifier follows each key's IL2CPP metadata literal through a tagged string pointer, GOT relocation, ARM64 ADRP/LDR load, and **register x2** into a matching constructor. It independently computes the constructor's **w1 BaseID** from ARM64 instructions and checks it matches the numeric suffix:

| Key | Constructor category | BaseID |
|---|---|---:|
| `skill_name_middle283166` | `ConfBattleSkillAttackItem` | 283166 |
| `skill_name_middle611111` | `ConfBattleSkillAttackItem` | 611111 |
| `skill_name_middle790267` | `ConfBattleSkillAttackItem` | 790267 |
| `skill_name_middle81092` | `ConfBattleSkillAttackItem` | 81092 |
| `stepName710506` | `ConfBattleStepBaseItem` | 710506 |
| `stepName710508` | `ConfBattleStepBaseItem` | 710508 |

Constructor RVAs: SkillAttack `0x5d4eccc`; StepBase `0x2869904`. **6/6 native name arguments and 6/6 corresponding BaseIDs verified**. No new English translation was recovered for these six keys. They must remain `NO_EXACT_LOCALE_RECORD`, not be replaced by similar-looking numeric keys. Their actual runtime fallback behavior is still unknown.
