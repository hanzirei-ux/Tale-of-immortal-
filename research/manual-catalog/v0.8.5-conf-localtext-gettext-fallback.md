## Verified native methods

IL2CPP metadata and exact module method-pointer table (matching native SHA-256 `c477a5637b89f78ca449ff65ad4c9137296ba680923b602db50831ecb5901099` and metadata SHA-256 `9be3762476a87e8be23e3fa589b44f084027a5c7f1ff78b9be5f013fb5d131b3`) resolve:

- `ConfLocalText.GetText(key)`: RVA `0x55f1060`.
- `ConfLocalText.GetText(key,language)`: RVA `0x55f13b8`.
- `GameTool.LS(key)`: RVA `0x456a018`.
- `GameTool.LS(key,flag)`: RVA `0x456a070`.
- `GameTool.TextToData`: RVA `0x456aeb8`.

`GetText(key)` uses dictionary indexer at `0x6ef3c34`, whose missing-key path calls error helper `0x76f3cd4`. `GetText(key, language)` uses `TryGetValue` at `0x6ef5450`, but on a miss goes to that same indexer. Neither automatically maps missing keys to English. Explicit language values select Chinese (default, field +0x20), Traditional Chinese (1, +0x28), English (2, +0x30) and Korean (3, +0x38).

The manual name helper `GameTool.LS(key)` passes flag `1` to `GameTool.LS(key,flag)`; it checks `TryGetValue` first. On miss, it inspects UTF-16 characters. If all are ASCII (<0x80), it selects a verified IL2CPP **empty-string literal** (metadata literal index 0), then calls `GameTool.TextToData`. If an input contains a code unit >=0x80, it provisionally retains the original string before TextToData. This is **static conditional code-flow evidence**, not an observed runtime UI response. Other callers may throw on missing keys.
