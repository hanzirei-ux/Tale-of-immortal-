# Tale of Immortal Android — v0.8.8 Verified Step/Ability BaseID → NameKey Mapping

**2026-11-01 — Read-only static ARM64 research.** No game APK, DEX, SO, save, or existing Mod Menu v0.3.6 feature was changed.

## Breakthrough

On the previously pinned, matching `libil2cpp.so` and `global-metadata.dat`, traced actual `ConfBattleStepBaseItem` constructor calls (**15**) and `ConfBattleAbilityBaseItem` constructor calls (**81**). A deterministic interpreter cross-references `ADRP/LDR` native GOT relocations, tagged IL2CPP string literals, the name argument in `x2`, and the numeric BaseID argument in `w1` (including optimized `MOV/MOVK/ADD/ORR` sequences).

All **12 Step BaseIDs** and **41 Ability BaseIDs** observed in the user's whole-save manual candidate scan have explicit constructor name-key evidence. These 53 verified BaseIDs cover **2,016 Step + 4,147 Ability = 6,163 candidate records** from the 8,024-record `DataUnit.cache` scan.

The remaining **1,861 Skill candidates** correspond to 58 distinct Type/BaseID pairs and have usable `skill_name_middle<BaseID>` keys via the established family pattern, but not all 58 individual native constructor sites have been verified in this milestone. In total, **8,024 / 8,024** candidates now have a matched, non-placeholder English-language **base-name component** in the game's compiled localization data. This is **not** 8,024 distinct/manual player-owned books or full titles.
