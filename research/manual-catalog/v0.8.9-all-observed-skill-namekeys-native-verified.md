# Tale of Immortal Android — v0.8.9: All observed manual base-name keys native-verified

**2026-11-01 | Read-only offline research.** No APK, DEX, JNI, SO, original game save, or functional Mod Menu v0.3.6 feature was modified.

## New result

The original matching IL2CPP ELF and metadata were checked against the existing SHA-256 baseline. We disassembled the native configuration region and identified **1,568** calls to `ConfBattleSkillAttackItem`'s constructor. A statically validated ARM64/GOT/string-literal interpreter recovered numeric BaseID passed in `w1` for all 1,568 constructor calls and name-key passed in `x2` for **804** calls.

All **58 observed Skill Type/BaseID pairs** in the original full-save manual candidate scan have exact `w1 → x2` mapping and match the previously inferred `skill_name_middle<BaseID>` key without conflicts (**58/58**). These pairs account for **1,861** Skill candidate records. Other 764 constructor calls do not have an independently resolved nonzero name literal; no inference about their translated titles is made.

From the previous v0.8.8 Step/Ability audit, an additional **12 Step BaseIDs** (2,016 candidate records) and **41 Ability BaseIDs** (4,147 candidate records) already had verified native keys. Combined: **111/111 observed Type/BaseID pairs** and **8,024/8,024 whole-save manual-like candidate records** now have direct native constructor-backed **base-name localization keys** and exact non-placeholder English base-name components from the earlier compiled language table.

## Important limits

- These are **8,024 manual-like records across multiple units in the entire save**, not 8,024 player-owned books.
- The earlier private **183-instance/71-key** sample has **not** been identified or joined in this research step.
- A native base-name key/English component **does not** establish a generated manual's complete on-screen title. The prefix selector, localization layout and instance identity still matter.
- Grade is not Level. No real displayed manual Levels or complete generated titles have been UI-confirmed.
- No DEX, APK, native library or save modification was performed.
