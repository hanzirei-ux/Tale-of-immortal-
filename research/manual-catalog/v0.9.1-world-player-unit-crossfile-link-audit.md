# Tale of Immortal Android — v0.9.1 World-to-Unit Candidate Link Audit

**2026-11-02 | Read-only offline analysis.** Original APK, Mod Menu v0.3.6 DEX, native SO, game save and previous functioning cheats remain unchanged.

## Result: strong provisional player-unit candidate

The original matching `DataWorld.cache` exposes the `DataWorld+World` schema, which contains a string field named `playerUnitID`. The initial serialized `World` value region contains **exactly one six-character identifier** that matches the **2,073** independently verified structural unit IDs of the original `DataUnit.cache`. The matching ID has a single unit anchor and an interval containing **24 manual-like candidate records**.

**Crucial qualification:** This is **high-confidence positional and cross-file evidence**, **not a complete typed deserialization proof** that this particular string is the `playerUnitID` field's stored value. Preserve this qualification until a typed field reader or runtime cross-check is available. The 24 rows belong to the matching structural unit interval; they are **not proof of a complete player-owned inventory**.

Prior native research (v0.7.5) found that **11 prefix entries** yield a **conditional Level 6** for modeled `Grade - gradeMin` differences in **-10..10**. The 23 instances here are **not asserted to be UI Level 6**: this milestone did not verify each individual `gradeMin`, and the runtime UI has not been inspected.
