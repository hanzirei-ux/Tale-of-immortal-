# Tale of Immortal Android — v0.9.4: UInt16 BaseID decoder correction

**2026-11-02. Read-only offline research.** No original game save, APK, DEX, SO, JNI or functional Mod Menu v0.3.6 features were modified.

## Critical correction to previous candidate totals

The v0.8.7 scanner decoded serialized numeric tag **3** as signed Int16. This incorrectly rejected high-bit BaseIDs (for example bytes `3f 85`, i.e. unsigned **34111**, had been misread as **-31425**). Tag **2** still correctly represents the signed `-1` separator between the prefix ID and prefix value lists. Correcting tag 3 to unsigned recovers **4,109** additional coherent manual-like arrays from the *same pinned original save*, while preserving **all 8,024** previously included records with no changes to their Type/BaseID/Grade/ordered prefix values.

## Native verification

All **74 newly recovered distinct Skill BaseIDs** have exact base-name keys matching the compiled English localization table and were traced to real `ConfBattleSkillAttackItem` constructor calls. Native disassembly follows the actual constructor arguments: numeric BaseID in **w1**, name localization string in **x2**. Together with the previously native-verified 111 pairs, **185/185 observed Type/BaseID pairs and 12,133/12,133 whole-save candidates** now have verified *base-name localization keys*. This **does not establish full generated manual titles**.
