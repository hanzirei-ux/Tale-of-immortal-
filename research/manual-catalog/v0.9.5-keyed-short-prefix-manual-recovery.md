**2026-11-02 — READ-ONLY offline research.** No original game save, APK, DEX, native SO, JNI or existing Mod Menu v0.3.6 gameplay cheats were modified.

## Corrected full-save scan

The v0.9.4 parser matched only manual-like `PropsData.values` arrays with 3–11 prefixes (**12,133** records). A stricter **instance-key-backed** parser validates each six-character UTF-16 instance identifier, declared tagged payload byte-length, number of typed values, Type/BaseID/Grade range, and exact prefix ID/value pairing. It recovers **817** previously excluded rows with **two** prefixes and **two** rows with **zero** prefixes (no qualifying one-prefix row).

**Total now 12,952 manual-like candidate records** across **2,073 unit intervals**, and **187 distinct Type/BaseID pairs**. All original **12,133 v0.9.4 rows are preserved exactly**, including offset, Type, BaseID, Grade, ordered prefix IDs and ordered values. Prefix distribution: `0:2, 1:0, 2:817, 3:432, 4:1300, 5:2046, 6:2070, 7:1734, 8:2091, 9:1289, 10:659, 11:512`. These are **not** counts of player-owned books and do **not** guarantee coverage of every other possible serialization format.

The two newly observed Type 1 BaseIDs are **11412** and **11413**. Both were independently traced through original ARM64 `ConfBattleSkillAttackItem` constructor argument `w1` (BaseID) and `x2` (actual localization key) and matched to the pinned native dictionary:
- `11412 → skill_name_middle11412 → Aether Fire`, constructor call RVA `0x5c86008`.
- `11413 → skill_name_middle11413 → Aether Blade`, constructor call RVA `0x5c86460`.

With the 185 existing mappings, **187/187 Type/BaseID pairs have native-backed base-name localization keys**. This is **not** proof of complete generated titles or UI rendering.
