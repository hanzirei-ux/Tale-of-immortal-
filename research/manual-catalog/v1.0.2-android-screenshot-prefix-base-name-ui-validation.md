User screenshots from a city Manual Pavilion also provide **19 truncated two-prefix shop labels** from floors 1F, 3F, 4F and 5F.

Reusing the exact original native references delivered in v1.0.0 and v0.8.3:

- **9/9** screenshot detail titles parse as `native group-1 prefix + space + native group-2 prefix + space + exact localized base name`.
- **18/18** detailed prefix parts match their correct native constructor-defined 200-entry group: group 1 IDs 1–200; group 2 IDs 201–400.
- **9/9** screenshot base-name components have an exact English localization-key match from the game-compiled dictionary.
- **19/19** visible shop prefix pairs also match the two native groups. The storefront text does **not** show the base-name component, so those 19 are **not** full-title confirmations.

Illustrative UI examples:
- `Step's Powerful Dance`: group 1 constructor row 187, group 2 row 377, base localization key `stepName16`; observed Grade II, category Motion.
- `Crusher's Clouded Compendium`: group 1 row 44, group 2 row 201, base key `ability_name_last5`; observed Grade I, category Mind Skill.

The full nine-row transcribed screenshot QA CSV and all shop observations are provided in the **private user-facing** v1.0.2 ZIP; they are **not** committed to the public repository.

## Important qualification: UI title structure validated, save-instance identity NOT validated

**0/9** screenshot detail title strings exactly match any of the **183 candidate full titles** derived from the historical `propData` sample in v1.0.0. The screenshot examples are shop items; the 183 set spans different saved units and does not represent those nine identifiable shop instances. This is consistent with different generated prefixes for different instances. It **does not disprove the name generator**, but it absolutely **does not validate any of the 183 reconstructed instance-specific titles or Levels**.

The screenshot `Skill Cultivation(N)` number matches the number of displayed numbered bonus rows (for instance N=2 gives II/III; N=6 gives II–VII). This observation **does not prove** `N == offline Level` for any same-save instance. The Roman-numeral `GRADE I/II` display is a separate axis. Do not conflate Cultivation, Grade, Realm, reconstructed Level, or rarity.

**In-game validation established only for nine observed display titles and the native component/ordering grammar**. It has **not** established 183/183 live-verified titles or Levels or any working Add Manual/DEX catalog implementation.
