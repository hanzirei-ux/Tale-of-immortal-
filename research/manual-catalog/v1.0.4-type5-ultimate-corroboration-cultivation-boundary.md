## UI label `Skill Cultivation(N)` is not yet tied to save-derived `Level`

The nine user Android screenshot pages show that the parenthesized N equals the number of visible bonus lines labelled starting from II (N=2 displays II–III; N=6 displays II–VII). Grade I occurs with different N values (2, 4, 5); Grade II occurs with N=5 or 6, independently showing Grade and Cultivation counts are separate axes.

A search for the literal `Skill Cultivation` in matching native assembly locates its usage in localization string initialization code, **not a verified UI numeric getter**. The screenshot items do not share a proven saved instance identity with the 183 sample entries. Accordingly **there is no evidence yet that N equals `MartialInfoData.get_level` for a particular instance**. Continue to distinguish: stored Grade, gradeMin, reconstructed offline Level, displayed Skill Cultivation N, Realm, and Rarity. No previously reconstructed Level was promoted to UI-verified.
