## Full extracted item-name set

The matching compiled native localization table contains exactly **3,268** keys of form `item_name<ID>` with unique integer IDs. **3,253** English-column strings are non-placeholder English candidates and **15** contain Chinese fallback; **3,253** IDs also have matching `item_desc<ID>` locale keys. **259** distinct display-name strings are shared by multiple IDs, involving **1,376 records**. Name text is not an item identity.

A broad **899-record `30...` ID-group review slice** contains balm, incense, ring, mount, artifact and outfit-looking names. It is a *mixed browse hint*, **NOT** 899 officially confirmed equipment; any equipment filter requires exact runtime configuration/type joins. The existing phone dump previously had **3,284 runtime IDs** for nonhidden items, but its per-ID data was **not available for exact matching in this active work environment**. The difference between these counts must not be interpreted as exactly 16 missing items: source scopes differ.

## Manual names and templates

- **810** metadata name-like localization keys: **681** English-component candidates, **118** Chinese/untranslated, **5** original `???` placeholders, **6** keys without an exact compiled-locale match.
- **187** observed and constructor-backed `(MartialType, BaseID)` template mappings, arising from **12,952** manual-like records across the whole saved world. This is not an exhaustive list of all skills defined in the game, nor a player inventory count.
- **183** private historical reconstructed full-title candidates and offline Levels remain available for QA only. They span multiple units. Do not treat them as live-screen-verified book names/levels or as Add Item IDs.
- Type names: Type 1 Martial, Type 2 Special, Type 3 Motion, Type 4 Mind Skill (Android screenshot evidence), Type 5 Ultimate (strong native/gameplay corroboration; direct Android screenshot still pending).

## Offline output and design implications

The private user-facing `TOI_v105_All_Names_Catalog_Preparation.zip` includes an **offline, locally searchable browser with 4,265 total entries** (3,268 item names + 187 observed manual templates + 810 manual name-key components), exact-source UTF-8 CSV/JSONL indexes, a separate **899-row non-authoritative gear review**, the **private 183-instance sample**, and a script that can exact-ID-join a future real phone runtime catalog. **25/25 unit tests PASS; ZIP CRC PASS.**

The offline HTML is only a **data QA viewer**, not a Mod Menu APK, DEX update, working Add Item action, or simulated gameplay. All item `raw_props_type`, official equipment subtype, Grade, Realm, Rarity and runtime availability remain UNKNOWN until joined to relevant runtime native configuration data. **Item ID and Martial BaseID are distinct namespaces.** A BaseID must never be fed to normal Add Item. `Add Manual` is not implemented, and DEX-only data/UI changes cannot invent native JNI functionality for hidden rows or complex manually generated martial instances.
