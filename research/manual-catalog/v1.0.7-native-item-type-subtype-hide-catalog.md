## Exact name joins and missing rows

Among **3,268** extracted `item_name<ID>` localization keys, **3,248** match a compiled `ConfItemProps` item ID. **61** native item configurations have no exact compiled name-key row and must remain ID-visible with name status UNKNOWN. **20** localization name keys have no matching native item configuration and must remain “locale-only / unavailable for native item lookup until proven otherwise.” **393/395** gear entries have exact name matches and **2** lack one.

The existing separate **860 named manual constructor templates** and **810 manual name-key components** are preserved.
