## Direct constructor source-name recovery

Original hash-pinned IL2CPP `ConfItemPropsItem..ctor` at RVA `0x340a2dc` stores its `x2` string pointer at object offset `+0x18`. Replaying the static ARM64/GOT→IL2CPP metadata string-literal references across four `Init` blocks traced **3,309/3,309 constructor argument x2 strings**. All were explicit `item_name...` keys. **3,308** keys equal `item_name<ItemID>`. Exactly **one** is a cross-ID alias: **item ID 7000157** references **`item_name7000156`**, whose English localized text is **“Elixir made by other disciple”**. ID 7000157 remains a distinct ID. The alias was proven directly from the native constructor and is not inferred from number similarity.

Previously **61** native item configurations had no *same-ID* `item_name<ID>` entry in the recovered compiled locale. Reading their actual x2 keys resolves **one** through the alias and leaves **60** with correct, fully recovered name keys **but no matching compiled English text**. No placeholder English translation is treated as real. All 61 legacy gaps were nonhidden (`hide=0`). Major unresolved groups are **30** raw subtype 619, **eight** raw Type 2, **seven** raw subtype 615. These groupings do not imply common names.

**Totals remain unchanged**: 3,309 configured item IDs; 25 native-hidden; 3,284 nonhidden; 20 locale-only `item_name` keys without native `ConfItemProps` constructor.
