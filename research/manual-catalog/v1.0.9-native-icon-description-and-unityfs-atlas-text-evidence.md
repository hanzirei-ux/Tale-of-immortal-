# Tale of Immortal Android — v1.0.9: Native Item Icon/Description Keys and UnityFS SpriteAtlas Text Audit

**2026-11-02 | Read-only offline research, not a gameplay patch.** No APK, DEX, SO, JNI, save, working v0.3.6 Mod Menu feature or original AssetBundle changed.

## Native item name/icon/description crosswalk

Across all **3,309** real `ConfItemPropsItem` native constructor calls, static ARM64 argument and stack analysis recovered **3,309 name keys, icon keys and description localization keys**. Of these, **1,033 distinct icon keys** exist. **3,244** description localization keys have compiled localization text, **65** do not. Original untranslated **60 item names remain untranslated**; two of these 60 have only generic localized descriptions. Native configuration scopes are unchanged: **3,309** configured item IDs, **3,284** not hidden, **25** hidden; **395 Gear**, separate from **860 named Manual constructor templates** and **810 Manual name-key components**.

## Actual decompression of UnityFS SpriteAtlas data

The matching original AssetBundle `spriteatlas_commonpropiconspriteatlas.ab` in the user's `assetpack_008.zip` (compressed bundle length **3,070,956 bytes**) was decoded using its **UnityFS block-info and LZ4 data blocks**. The serialized Unity object stream contains **1,031/1,033 exact icon-key strings as four-byte little-endian length-prefixed values**. All **174** `spriteatlas_*.ab` bundles across the user's 17 assetpack ZIPs were decompressed and scanned; no additional distinct icon key was recovered beyond these **1,031**.

**3,280/3,309** item configurations use those structurally matched atlas-name strings. **29** records have unmatched keys, entirely explained by two labels: **24** rows with placeholder `0`; **five** Shadow Beast Mounts using `anyingshou`. The latter has not been found in the scanned SpriteAtlas string pools and might be composed through another icon source. Do not imply the image is absent from the game.

**Crucial proof boundary:** this confirms the **name token appears in a serialized SpriteAtlas bundle**, not that the item icon texture pixels or Sprite class instance were extracted, atlas rect verified, or its image visually matched on Android. **Zero** sprite image extractions, **zero** device visual checks and **zero** Add Item operations were performed in this research milestone.
