# Tale of Immortal Android — v1.1.0 Native Item Level and Mount Grade Separation

**2026-11-02. Read-only binary/metadata audit; no APK, DEX, SO, JNI, save, or working v0.3.6 Mod Menu changes.**

## All 3,309 configured Item IDs have a recovered native `level`

Matching Unity IL2CPP metadata v31 defines `ConfItemPropsItem.level` (type index **4408**, field index **15323**). The native constructor at RVA `0x340a2dc` reads it from its integer stack argument at original caller `[sp+8]` and stores it at object offset `+0x40`. An original-callsite ARM64 read-only trace across four configuration initializers recovered **3,309/3,309 item IDs and levels**, with no unresolved entries:

This is **the native field called `level`**, *not* a verified item Grade, Realm, Rarity, Skill Cultivation or UI title. The earlier 3,284 nonhidden configurations, 25 hidden configurations, 395 Gear, 860 named Manual constructors, 810 Manual name components and icon/description joins remain preserved.

## Distinct native `grade` field for 56 Mounts

The separate `ConfItemHorseItem` type index **4394**, field index **15273**, contains a genuine `grade` field. The constructor at RVA `0x3379d08` stores incoming `w7` to that field. Examining all **56** exact constructor calls in `ConfItemHorseBase.Init1` (RVA `0x3379ee4`–`0x337b9c4`) yields **56/56 stable Item ID joins** against the **56 Gear subtype 302** configs. Mount-specific grades span **1–10** and are separate from their parent item `level` (1–6). For example, Item ID **3021021**, Tenghuang, has native item Level **6** and horse Grade **8**. **No direct Android UI Grade rendering was confirmed**. This Mount-only field must *not* be copied to Ring, Outfit or Artifact.

## Why text G1–G6 is not a universal grade formula

Exactly **1,143** original English item-name strings show an isolated `G1` through `G6` token. **1,100** conform to `G+native_level=7`, but **43 are exceptions** (for example, some soul components, comprehension materials and herbs). Therefore **no universal Grade from Level conversion** is valid. Grade of other categories and actual Realm/Rarity remain UNKNOWN until individually sourced.

Other arguments `playerShow`, `npcShow`, `isOverlay`, `drop`, `dieDrop`, `auction`, `sale`, `worth` and `isMultiDrop` were read as native numeric fields; this is not verification of their display, use or addability semantics.
