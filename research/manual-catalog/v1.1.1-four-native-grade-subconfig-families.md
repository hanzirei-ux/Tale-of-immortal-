# Tale of Immortal Android — v1.1.1: Four distinct native Grade configuration sources

**2026-11-02 | Read-only IL2CPP metadata and ARM64 static analysis; no APK/DEX/SO/JNI/save/Mod Menu v0.3.6 modification.**

## 652 exact unique item IDs with specific native Grade

| Family | Exact source | Item IDs | Native Grade range |
|---|---|---:|---|
| Ring | `ConfRingBaseItem.grade` | **34** | 1–10 |
| Mount | `ConfItemHorseItem.grade` (from v1.1.0) | **56** | 1–10 |
| Pill/Elixir | `ConfItemPillItem.grade` | **458** | **0–10** |
| Rarity Materials | `ConfItemRarityMaterialsItem.grade` | **104** | 2–10 |
| **Total non-overlapping** | | **652** | |

All records match real Item IDs from the previously decoded 3,309-entry `ConfItemPropsItem` catalog. Grade field names are confirmed from original IL2CPP metadata, and per-record values from unmodified ARM64 constructor or inline-initializer instructions.

- **Ring:** 34 direct inline record writes in `ConfRingBaseBase.Init1` RVA `0x393d69c–0x393e2f4`. Object `+0x18` stores a packed 64-bit value: low32 = `grade`, high32 = `capacity`. Example Sinking Stone Ring item ID `3011011`: specific Grade 1, capacity 12, generic `ConfItemPropsItem.level` 4.
- **Pill:** 458 distinct constructor calls from `ConfItemPillBase.Init1` RVA `0x337d6f4–0x338cfd4`; the `ConfItemPillItem` constructor at `0x337d4a4` stores caller stack `[sp+8]` to object `+0x3c`, the specific native `grade` field. **10/458** entries have exact Grade **0**; preserve them. Example G1 Benevolence Elixir ID `3000556`: Pill Grade 10, generic Item Level 6.
- **Rarity Materials:** 104 exact direct inline constructor records in `ConfItemRarityMaterialsBase.Init1` RVA `0x34173a4–0x34195a4`, packed object `+0x20` low32 = `grade`, high32 = `hunger`. Example Sandbury Bone ID `5081015`: Grade 2, generic Item Level 5.
- **Mount:** the earlier 56-record Grade recovery is retained exactly; no reclassification or reinterpretation.

**Do not confuse:** native config-specific Grade with generic Item `level`, textual `G1–G6`, Realm, Rarity, Manual Grade, `Skill Cultivation(N)`, or UI-display Grade. No Android UI Grade verification was performed. **2,657** other configured item IDs lack one of these four verified specific Grade sources; this does *not* mean they have no Grade in the game. **295 Outfit and 10 Artifact** are deliberately not assigned an inferred native Grade.

**Preserved:** all 3,309 Item IDs (3,284 nonhidden, 25 hidden), 395 Gear, 860 constructor-backed named Manual templates and 810 standalone Manual name components. No manual BaseID was substituted for an Item ID.
