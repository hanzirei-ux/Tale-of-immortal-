# Tale of Immortal Android — v1.1.1 Native Grade Field Audit for Rings and Pill Configurations

**2026-11-02 — Read-only offline audit.** No APK, DEX, SO, JNI, save, or working Mod Menu v0.3.6 feature was changed.

## Ring: the `grade` field is an Item ID, not a quality grade

The native `ConfRingBaseItem.Init1` method at RVA `0x393d69c` stores its field named `grade` at object offset `+0x10`. The static ARM64 reconstruction recovered **34/34 raw values**, and each joins exactly to an existing Ring item ID in `ConfItemPropsItem`, subtype 301. Therefore `ConfRingBaseItem.grade` cannot be used as a numeric Ring quality filter. Other Ring fields like `lockScore` and capacities need separate semantic verification.

## Pill: 1,458 raw grade field values, but not the UI G1–G6 grade

`ConfItemPillItem..ctor` (RVA `0x337d4a4`) reads a caller stack value into object field named `grade`, at `+0x38`. The exact initialization blocks contain **1,458** constructor calls; **1,458/1,458** raw grade values were traced:

| Raw `ConfItemPillItem.grade` | Count |
|---:|---:|
| 0 | 1,343 |
| 50 | 23 |
| 150 | 23 |
| 350 | 23 |
| 620 | 23 |
| 980 | 23 |
| **Total** | **1,458** |

**1,456** of these Pill constructor item references join against exact IDs in the 3,309-item `ConfItemPropsItem` catalog. **Two** cannot be exact-matched and remain excluded from action-capable UI plans. Example: the source labels G5 Fire Fruit with raw value 50 and G4 Fire Fruit with 150; therefore the raw value is **not** ordinal display Grade. No Realm/Rarity semantics are proven.

## Scope retained

The verified previous index remains **3,309** native configured Item IDs, **3,284** nonhidden and **25** hidden; **395** Gear, **860** native-named Manual templates and **810** manual localization components, **20** locale-only item name keys; **4,999** browsable offline entries. The original v1.1.0 `ConfItemPropsItem.level` for all 3,309 items, separate **56 Mount** native Grade values, 1,033 icon keys and localization descriptions are preserved. Outfit/Artifact-specific grade/realm/rarity remain unknown.

The user-facing private `TOI_v111_Grade_Field_Semantics_Catalog.zip` contains original-source trace scripts, exact-ID CSV/JSONL field audits, an offline searchable HTML index, and **46/46 offline v1.1.1 PASS plus 51/51 v1.1.0 regression PASS**. ZIP CRC passed. The private full ZIP, proprietary extracted localization tables, game native binary/metadata or save must not be posted on public GitHub.
