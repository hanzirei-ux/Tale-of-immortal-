# Tale of Immortal Android — v1.1.1: Ring & Pill Native Grade Field Semantics

**2026-11-02 — read-only IL2CPP research.** No APK, DEX, SO, JNI, game save, or working v0.3.6 Mod Menu feature changed.

## The native property named `grade` cannot be used as a universal UI Grade

**Ring:** Matching IL2CPP metadata names the first field of `ConfRingBaseItem` as `grade`. Its native `Init1` RVA `0x393d69c` writes 34 constants to object offset `+0x10`. All **34/34 values match the exact Item IDs** of the 34 `ConfItemPropsItem` Gear subtype 301 Ring configs. Examples: `3011011` and `8103601`. This is an **ID-bearing configuration field, not an ordinal quality Grade**. Do not display it as grade 1–10.

**Pill:** The `ConfItemPillItem` constructor RVA `0x337d4a4` takes its native `grade` field from the first caller stack argument `[sp]`, stores it at object offset `+0x38`. Across `ConfItemPillBase.Init1` and `Init2`, **1,458** constructor calls were recovered with **1,458/1,458** numeric `grade` values:
- `0`: **1,343** entries;
- `50`, `150`, `350`, `620`, `980`: **23 entries apiece**.

The call's first integer argument permits **1,456/1,458 exact Item ID joins** to the existing **3,309** native item configurations. **Two** Pill calls cannot be exact-matched and are excluded from actionable catalog rows. These raw `grade` numbers are **not G1–G6 grades**. No gameplay use-site or UI semantics for these raw values is verified; do not invent them.

**Mount:** The previously audited `ConfItemHorseItem.grade` remains a **separate native grade 1–10 field for 56/56 Mounts**; this is not automatically the same type or meaning as Ring/Pill grade. An actual Android same-instance Grade display is still pending. The grade, rarity, and realm semantics of **295 Outfit** and **10 Artifact** entries remain unknown; no grade conversion is manufactured from their names.
