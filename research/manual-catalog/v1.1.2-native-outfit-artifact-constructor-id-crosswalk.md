## Outfit 295/295: verified native IDs and raw attributes

The original matching binary metadata identifies `ConfClothItemItem` (type index **4034**) with constructor at RVA **0x2c79f08**. Its initializer at **0x293227c** makes exactly **295 direct constructor calls**. Read-only ARM64 tracing recovers **295 distinct inherited Item IDs**, and all **295/295** match the existing 295 `ConfItemPropsItem` Outfit configurations (Gear subtype **304**), with no unmatched IDs in either group.

The `w1` argument is the inherited base Item ID at object offset `+0x10`. The subsequent subclass fields are `clothID` (`w2`), `sex` (`w3`), `style` (`w4`), `color` (`w5`), `modelID` (`w6`), `itemCost` (`x7`) and `weight` (stack). All integer arguments `w1`–`w6` were recovered for all 295. **sex code 1:147, code 2:148**; **color code 1:111, code 2:92, code 3:92**; there are **295 unique clothIDs** and **111 unique style codes**. Model IDs **31001:147** and **32001:148**. These are exact raw codes; do not map to male/female or specific color names without UI proof.

There is **no declared quality Grade field** in this Outfit class, and `ConfItemPropsItem.level` remains separate and is not verified as an Outfit quality grade.

## Artifact 10/10: true `initGrade` is separate from inherited Item ID

The matching `ConfArtifactShapeItem` (type index **3750**) constructor at **0x594da8c** is called ten times from initializer **0x594dd28**. The **10 distinct inherited Item IDs** exactly match the **10 Gear subtype 401 Artifact** configurations.

**Critical offset distinction**: `w1` at object offset `+0x10` is the inherited Item ID, **not** the subclass `initGrade`. The subclass `initGrade` comes from **`w2` at offset `+0x18`**; the ten static native values span **2–10** (value 3 occurs twice). Additional constructor-backed fields include `skillID` (`w3`), `prefixInit` (`w4`), `perfixMax` (`w5`), and `durable` (`w6`). This is a real **initial native Grade field**, not a verified live current Grade after improvements or an Android UI confirmation.
