## Outfit: group variants without inventing color or sex labels

The **295 native Outfit constructor records** (every Item ID matches the exact Gear subtype 304 item catalog) form **111 unique tuples of `(sex_code, style_code)`**:

| Exact native variant pattern per style | Number of style groups | Outfit item rows |
|---|---:|---:|
| Color codes **1, 2 and 3** | **92** | **276** |
| Color code **1 only** | **19** | **19** |
| **Total** | **111** | **295** |

Native modelID `31001` accompanies sex_code `1` (147 items, 55 style groups); modelID `32001` accompanies sex_code `2` (148 items, 56 style groups). **Neither numeric sex-code value nor the actual 3 color-code values have yet been verified against an Android UI gender/color label.** The 19 one-color style groups cannot be offered hypothetical color 2/3 variants by a picker.

Because the stock locale name is often just **“Outfit”**, a read-only picker can now use **295 unique, non-fabricated technical display labels** in the form `Outfit | Model <native ID> | Style <native ID> | Color code <native ID>`. Item ID remains the actual identity. This is not a claim of a rendered Outfit preview or working Add Item action.

## Artifact: all 10 skillID→SKILL_ATTACK native base names

The matching **10 Gear subtype 401 Artifact** records each contain a `ConfArtifactShapeItem.skillID`. All **10/10** resolve to a distinct exact BaseID within the prior 860 named manual/skill constructor mappings, and all 10 belong to the native **SKILL_ATTACK** constructor family with a compiled English **base-name** localization key. Representative independent verified joins:

| Artifact | Skill BaseID | English base-name component |
|---|---:|---|

**Important distinction:** The joined text is the associated skill's localized *base-name component*—not its runtime state, an item icon, a generated two-prefix Manual title, proof of successful skill application, or a usable Add Manual identifier. An Artifact `Item ID` and skill `BaseID` are two different namespaces. Artifact `initGrade` remains a separate **initial** configuration field, not current upgraded Grade.
