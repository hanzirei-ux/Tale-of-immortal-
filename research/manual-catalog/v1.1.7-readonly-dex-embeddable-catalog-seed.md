## Deliverable: compact, independently tested offline search data for an eventual DEX-only picker

The exact previous v1.1.6 source CSVs were converted into **5,045 uniquely namespaced UTF-8 TSV records** with stable keys and source status labels. The data are intentionally kept separate from gameplay operations. The original **999,903-byte TSV** compresses to **78,255-byte deterministic GZIP**, then **104,340 bytes of Base64** split into **13 safe Java string-literal chunks** (8,192 chars each maximum). The generated pure-Java 8 `CatalogSeedV117.java` uses standard `java.util.Base64` and `GZIPInputStream` (Android API **26+**) to expose lazy immutable read-only rows and text search. Actual `javac` compilation and a JVM execution smoke test **PASS**; bundled Python provenance tests and ZIP CRC also **PASS**.

The item seed retains verified fields including raw native Type/Subtype, visibility, **native Level** (not automatically Realm or quality Grade), icon name-key, localization name-key, and original Outfit model/style/color-code labels. All **295 real Outfit variants** stay distinguishable, and **60 native Item IDs** lacking matching English localization remain visible under explicit untranslated-key placeholders instead of guessed names. Exactly **one known cross-ID name-key alias** (7000157 pointing to the native name key of 7000156) remains distinct by Item ID. The seed is a **browse/search-only helper** and explicitly reports no verified Add Item action.
