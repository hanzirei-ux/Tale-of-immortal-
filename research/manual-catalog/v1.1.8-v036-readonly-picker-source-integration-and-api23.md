The picker hands off **only an explicitly tapped nonhidden native Item ID** to the existing **live game catalog search field** after clearing any previously selected ID. The source package does not create an Add Manual capability.

## Android version compatibility improvement

The existing repository build helper `tools/build_menu_dex_only.py` runs D8 with **`--min-api 23`**. The earlier v1.1.7 Java seed referenced `java.util.Base64`, available only from Android API 26. The new `CatalogSeedV118` deliberately uses a small pure-Java Base64 decoder with `java.util.Arrays` and the same GZIP input, keeping all 5,045 rows and results unchanged while avoiding that API 26 dependency. This addresses a concrete Android API 23–25 compatibility risk without touching the native JNI ABI.
