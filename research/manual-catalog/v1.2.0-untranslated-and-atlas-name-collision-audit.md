## 27 SpriteAtlas path-name collisions

The previous private `TOI_Atlas_Paths_2447.csv` contains **2,447** paths obtained from ten selected UnityFS sprite atlases. This follow-up groups them case-insensitively by the path string itself:

- **2,420 unique sprite path names**;
- **27 names found in more than one atlas group**;
- **0 exact matches** between an Android visible numeric Item ID and a `<ItemID>.png` path in that ten-atlas path index.

Illustrative collisions include `jianfa.png` shared between common property and martial-info atlases and `type_1.png` through `type_8.png` shared between skill and ability atlases. The same filename in different atlases must not be assumed to represent the same icon object, texture, or usage. Lookup needs a qualified atlas source plus exact native icon-key and Unity object mapping, not `ItemID.png` inference.

**Crucial evidence limit:** zero exact filename matches does not mean missing artwork. The earlier [v1.0.9 icon-key audit](v1.0.9-native-icon-description-and-unityfs-atlas-text-evidence.md) identified **3,280/3,309 native item configurations with structurally matching icon key strings** in the serialized property atlas, although the images, sprite rects and actual per-item visual display remain unverified. An existing native *string* cross-reference is stronger evidence than a numeric filename shortcut.
