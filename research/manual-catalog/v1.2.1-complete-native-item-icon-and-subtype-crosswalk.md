## Direct original native constructor tracing

Using the matching pinned original `libil2cpp.so` and `global-metadata.dat`, four `ConfItemPropsItem` Init functions were disassembled and 3,309 original constructor calls traced: **1,000 + 1,000 + 1,000 + 309**. ELF relocation/GOT lookups and the IL2CPP encoded UTF-8 metadata string-literal tags recover direct arguments, not inferred filename or neighboring Item ID matches.

**All 3,309/3,309 original calls have a resolved:**
- native Item ID (3,309 unique);
- localized name **key**, icon key and description key (not all localized texts);
- raw Type, raw Subtype, native Hide flag, and native Level.

No unresolved fields among those eight fields. This extends the earlier [v1.0.9 native icon audit](v1.0.9-native-icon-description-and-unityfs-atlas-text-evidence.md) with a fresh reconstruction against the user's current files.

## Source-proven icon-key joins

- **1,033 unique native icon keys** across the 3,309 Item IDs.
- **3,280/3,309** items have native icon keys matching exact named Sprite entries in the previously decoded serialized `spriteatlas_commonpropiconspriteatlas.ab` Atlas path index.
- **24** have icon-key string `0` (placeholder), and **five** use `anyingshou`, absent from the indexed common property atlas names. The latter may use an alternate source; absence here is not proof artwork does not exist.
- Of **60** Android rows with untranslated fallback display names, **58** have matching atlas sprite-name evidence. The two exceptions are raw Type 2 Books **7000043** and **7000044**, each icon key `0`.
- Two untranslated Outfit IDs, **3042149** and **3042150**, both use native icon key `lilong`, which matches the serialized atlas path `lilong.png`. This does not establish their clothing style/color or missing English names.

**Proof boundary:** these are native **string key → serialized atlas sprite-name** joins. Neither actual Texture2D pixels, Unity Sprite rectangles, a rendered icon, nor device UI visual confirmation was extracted. No per-item addability, Grade, Realm, or Rarity assertion follows from this mapping.
