### Exact array copy mechanics

The source-proven `Clone` implementation reads:

- Object field **`+0x20`**, the array-valued `className` from the matching constructor and metadata.
- Array **`+0x18`** for its length, then allocates a fresh array with the same length through the original array allocator.
- A loop at **`0x5A7CA4C` / `0x5A7CA50`** copies each element using **`ldr w` and `str w` with index `lsl #2`**, an exact **4-byte element copy**.

Those source encodings were verified byte-for-byte at their RVAs. Thus `className` is preserved as a 32-bit-element array across a direct native Clone operation. This does **not** give the elements' semantic enum, actual gameplay value, icon identity, Manual Type, Grade or Realm.

The previous counts are unchanged: 81 AbilityBase rows, **40** original zero-length arrays and **41** three-element arrays.

## Reassessing the 13 FieldRef handles — do not promote defaults to gameplay values

The previously recovered 41 three-element array-initializer calls share 13 source handles. The static metadata-v31 field-reference decode associates **11** with `<PrivateImplementationDetails>` fields that have candidate default bytes. **Two** decode nominally to `SpriteState.m_HighlightedSprite` and `VFXSpawnerState.m_WrapEventAttribute` without matching field default records.

**Critical boundary:** These are *static token/fieldRef-table observations*. They are **not a verified mapping of the post-initialization runtime FieldInfo pointers** passed to `RuntimeHelpers.InitializeArray`, nor a reliable decoder of the final `className` payload. In particular, the two references outside `<PrivateImplementationDetails>` remain anomalous; do not silently interpret them as sprite icons or valid numeric array payloads. The 11 candidate 12-byte sequences from v1.2.9 must not be displayed as verified Ability stats.

The native array initialization helper has a `memcpy` path, while the AbilityBase Clone copies 32-bit elements. Neither alone proves the 13 static bytes are the exact runtime contents. **No actual Android runtime dereference or sprite visual confirmation occurred.**
