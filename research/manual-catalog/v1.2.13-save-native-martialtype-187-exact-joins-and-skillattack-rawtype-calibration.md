## New verification: 187 exact (MartialType, BaseID) pairs

A strict parser was run **directly on the user's original, gzip-decompressed `DataUnit.cache`** (SHA-256 `d7f72d635b42b0c39e122d5cbf3530b060e9b586b55d9f7532c0c6634253df6b`). It recovered **12,952** structurally framed manual-like records. Each candidate passed checks on:

- a six-character UTF-16LE instance identifier and the corresponding serialized value header;
- the declared payload length, declared typed-value count, and an exact end-position match;
- the integer tags/byte widths of all declared values, with the actual stored `MartialType` and `BaseID` decoded separately rather than guessed from numeric ranges;
- the native enum range 1–5 and a matching pair in the previously source-traced native constructor catalog.

All **12,952/12,952** records pass the strict structural read. They yield **187 unique (MartialType, BaseID)** pairs, **187/187** of which match the native constructor catalog's corresponding family/BaseID. The exact category counts are:

| Game enum `MartialType` | UI label | Unique pairs |

These are **pairs observed across the full saved world**, *not* 187 player-owned books, 187 unique English full titles, or an exhaustive count of every Manual template in the game. Exact player ownership and Add Manual eligibility remain unverified.

Of the 187 native-matched pairs, **146 have independently proven icon-key → Unity SpriteAtlas name associations**, and the remaining **41 are AbilityBase pairs whose icons have not been joined per BaseID**. All 187 have non-placeholder **native name localization keys**, not Android-verified full titles.
