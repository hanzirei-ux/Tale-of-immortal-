# Tale of Immortal Android — v1.2.17 Native English Manual Base Names and 400 Prefix Components

**2026-11-03 | Read-only verification.** No source APK, `classes2.dex`, game native binaries, user saves, AssetBundles, or functional Mod Menu v0.3.6 features were changed. This public report contains **aggregate statistics and short illustrative samples only**; complete derived translations/ID tables remain private to the user.

## Major verified finding: native localization constructor links key to English text

The original, SHA-256-pinned `libil2cpp.so` and `global-metadata.dat` contain a native text-entry constructor at **RVA `0x65AED20`**. ARM64 callsites load the localization key as `x2`, Chinese `x3`, Traditional Chinese `x4`, English `x5`, and Korean `x6`. Pointer provenance was traced through **ELF `R_AARCH64_RELATIVE` relocation**, GOT address, original static tagged IL2CPP string-literal token, and the metadata-v31 literal table.

An ELF virtual-address-aware static scan recovered **56,259 direct constructor calls**, **56,259 unique name keys**, and **56,193 nonempty English-string fields**. Source row indices span 1–56,263 with four unobserved technical indices (55,997, 55,998, 56,041, 56,042), so these callsites **must not be described as 56,259 consecutive indices**. The keyed map has no duplicate/conflicting keys.

Concrete independent examples:
- `skill_name_middle11412` → **Aether Fire**;
- `skill_name_middle11413` → **Aether Blade**;
- `skill_name_middle14111` → **Breeze Sword**;
- `ability_name_last1` → **Move**.

These are verified **base-name components in compiled text data**, not necessarily complete generated Manual titles shown by Android.
