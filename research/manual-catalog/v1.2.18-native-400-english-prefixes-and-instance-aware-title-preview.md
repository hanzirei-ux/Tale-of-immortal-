## Exact read-only native extraction of 400 prefix-name strings

From the original SHA-256-pinned ARM64 `libil2cpp.so` and v31 `global-metadata.dat`, **400 direct ARM64 constructor calls** to `ConfBattleSkillPrefixNameItem..ctor` (RVA **`0x2827be4`**) were independently traced. Original `w1` carries the row ID, `w2` the prefix-name group, and `x5` the **English language literal**. The extractor follows `ADRP/LDR`, x-register aliases, callee-saved register handoffs, and ELF `R_AARCH64_RELATIVE` relocation addends to the original tagged IL2CPP string literal table; it is **not** a translation via an external site or numeric-ID guess.

- All **400/400 native prefix constructor calls** have an exact integer row ID and an **English text component** recovered from `x5`.
- **Group 1:** 200 sequential IDs **1–200**.
- **Group 2:** 200 sequential IDs **201–400**.
- **Zero** missing IDs, duplicate IDs, or absent English components in the 400-row dataset.
- The Chinese/Korean alternative localization fields were **not** independently audited to completeness here; this finding is specifically the verified **English x5** column.

## Critical distinction: BaseID cannot generate its own full manual title

The user-facing **offline Android-compatible browser preview** now contains the original native 400 English prefix strings and the existing **897 namespaced standard Manual-name-key candidates** from v1.2.17. Of these:
- **722** have English *base-name* text directly paired by the original localization constructor.
- **175** remain unsuitable for a verified English preview (128 Chinese fallback, 5 `???` placeholders and 42 unmatched keys).
- **187** have **save+native exact MartialType/BaseID category** proof; **710** have provisional category assignments.
- **0** new per-instance full English titles or displayed Levels have been verified on Android in this milestone.

The browser permits searching by BaseID, localized base or name key, and choosing the **two distinct prefix indices explicitly** (first group 1–200, second group 201–400). Without *per-instance* prefix selector results, the browser **will not manufacture a final title from BaseID alone**. It labels all manually selected combinations **`SIMULASI_KOMBINASI_MANUAL`**. A convenience example selector uses the known 162/273/23111 regression, but is still labeled conditional, not necessarily the title of the selected user's inventory instance.

The catalog CSV preserves all 897 existing identity/category/name statuses, adds two intentionally blank prefix-index columns, an intentionally blank full-title column, and explicit `NEEDS_INSTANCE_INDICES` / no-Android-verification markers. **The absence of real instance indices is an intentional protection against fabricated displayed names.** Manual BaseIDs and ordinary Item IDs remain separate, and no native Add Manual functionality is claimed.
