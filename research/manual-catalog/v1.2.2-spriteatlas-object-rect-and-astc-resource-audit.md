# Tale of Immortal Android — v1.2.2 Unity SpriteAtlas render-data coordinates and ASTC resources

**2026-11-03 | Read-only offline analysis of the user's original AssetBundle archives.** No APK, DEX, JNI, save, or original binary/AssetBundle was modified.

## New result: actual serialized Unity objects and atlas rectangles

The matching original `assetpack_008.zip` holds:
- `spriteatlas_commonpropiconspriteatlas.ab` — UnityFS contains **1,210 real Sprite objects**, **two Texture2D objects**, one SpriteAtlas object, and one AssetBundle object.
- `spriteatlas_commonskilliconspriteatlas.ab` — UnityFS contains **665 real Sprite objects**, **one Texture2D**, one SpriteAtlas, and one AssetBundle object.

The Unity 2022 serialized-file type trees and object table were decoded directly. Both SpriteAtlas **m_RenderDataMap** collections were parsed and each 24-byte render-data key matched to the corresponding real Sprite object; each matched record includes Texture2D path ID and texture rectangle (x, y, width, height).

These coordinates are supported by actual SpriteAtlas rendering data, rather than guessed based on name strings. The three original ASTC texture payloads (1,048,576, 262,144, and 1,048,576 bytes) were recovered from the associated `.resS` UnityFS resource nodes. Valid standard ASTC 16-byte headers were prepended for private inspection; **no RGBA/PNG image decode or visual Android verification has been performed.**

## Cross-reference against the previous pinned native Item config

- **3,280/3,309** item configuration rows map to a real SpriteAtlas Sprite name, Texture2D path ID and render rectangle; multiple different Item IDs may share one icon.
- **24** configured item rows use icon key `0`, the known placeholder.

- **395 Gear** retained: 34 Ring, 56 Mount, 295 Outfit and 10 Artifact, all with previously recovered native subtypes.

## Verification limits

ASTC compression was not decoded into individual icon PNGs. Sprite rects use Unity coordinate origin; final visual crop orientation and pixel appearance should be validated when rendered via an ASTC decoder or the Android game. The native `level` field remains distinct from Grade, Realm and Rarity. There was **no** game-side Add Item or Add Manual call, compatibility test, DEX patch, APK build or modification of the working v0.3.6 Mod Menu.
