# Tale of Immortal Android — v1.2.22 GM menu deeper audit

2026-11-05. Read-only analysis of the user's original matching Android IL2CPP binary and source v0.3.6. No APK, DEX, save, native library or cheat behavior modified.

## GM search and action paths
Original UIPlayerGMSkill.UpdatePropUI reads ConfMgr.itemProps, localizes via GameTool.LS and performs partial-name matching. SetPropID retrieves an item by numeric ID. The item callback uses GameItemRewardData -> WorldUnitData.RewardItem for a positive reward; separate subtraction branches call DataProps.DelProps and WorldUnitData.CostPropItem.

For Manuals, InitMartial reads separate battleSkillAttack, battleStepBase and battleAbilityBase sources. UpdateMartialUI looks up their BaseIDs and prefix configurations. A skill reward callback constructs RandomGetRewardData, calls RewardTool.GetReward, then passes the generated reward to WorldUnitData.RewardItem. Ability paths also use ConfBattleAbilitySuitBase and suitID.

## Newly proven native category converter
ConfBattleSkillAttackItemEx.martialType (original RVA 0x51b9b84) directly converts technical types 1/2 to MartialType 1, type 3 to MartialType 2, and type 4 to MartialType 5. Original native lookup constants are [1,1,2], plus explicit type-4 return 5. Across 1,568 original SkillAttack constructor records this yields 1,437 Martial, 106 Special, 25 Ultimate **configuration records**. It does not prove that every configuration is an obtainable Manual. StepBase and AbilityBase remain separate.

## Mod Menu boundary and tests
The v0.3.6 JNI4 bridge catalog skips hidden entries and exposes 3,284 non-hidden item IDs; it uses RewardPropItem with count/stacking guards for ordinary items. Its fixed request allowlist does not expose the native GM's generated Manual-reward pathway. DEX-only can safely improve search and read-only presentation using existing verified catalog data, but cannot conjure new IL2CPP invocations.

Read-only assertions passed for six native GM call paths, original hash, native converter instructions and 1,568 category joins. This public note intentionally excludes game binaries, per-ID tables, private data and user files. No live device testing was performed.
