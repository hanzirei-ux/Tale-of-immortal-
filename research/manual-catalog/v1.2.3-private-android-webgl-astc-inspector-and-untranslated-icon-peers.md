# Tale of Immortal Android — v1.2.3 GPU ASTC Preview Preparation and Untranslated Name Audit

**2026-11-03 | Read-only research.** No game APK, DEX, native binary, save or existing Mod Menu functionality was modified.

## Why a browser-assisted ASTC preview was prepared

The previous v1.2.2 audit recovered three original ASTC 8x8 Texture2D payloads, with **1,210 item Sprite rects** and **665 skill Sprite rects**. Local host ASTC codec binaries were unavailable and installation of a Python ASTC decoder was blocked by network name resolution; **no host-side PNG conversion is claimed**.

A private offline Android HTML inspector was therefore prepared. It uses the standard WebGL2 `WEBGL_compressed_texture_astc` extension to upload the exact ASTC payloads, render a selected atlas, select a known Unity Sprite rectangle, preview a cropped icon and optionally export it locally as PNG. All user-provided assets remain local. A vertical flip control addresses Unity/GL orientation ambiguity.

- Static JavaScript syntax check (`node --check`) **PASS**.
- ASTC magic, format 8x8, dimensions and exact payload length for all **three files** **PASS**.
- 1,210/1,210 item Sprite rectangles, 665/665 skill Sprite rectangles validated in original texture bounds.
- Runtime item index contains 3,309 unique native Item IDs, 395 Gear rows and 60 unresolved English names.
- Package ZIP CRC test **PASS**.
- **No actual ASTC texture decode, Android browser/WebGL rendering, visual crop validation or PNG export has been tested on the phone.** Rendering depends on the browser exposing the WebGL ASTC extension. Do not treat the HTML as an APK or DEX patch.

## New name evidence — shared sprite is not a translation

Among **60** native item IDs whose Android collector name displays `item_name...`:

| Check | Number |
|---|---:|
| Exact native icon key joined to serialized SpriteAtlas object | **58** |
| Placeholder icon key `0`, not joined | **2** |
| Share a *nonplaceholder* icon key with one or more already translated item records | **44** |
| No named peer via same nonplaceholder icon key | **16** |
| Distinct icon keys across the 60 | **16** |

The large shared-icon groups include `mibaocangbaotu` (**30 item IDs**) and `fengleiwutongzi` (**7 item IDs**). Since icon keys may deliberately be reused across different IDs, **none of the 60 missing English names is considered recovered** based on icon peer text. Names remain UNKNOWN_PENDING_EXACT_LOCALIZATION. Native Level is not a verified Grade/Realm/Rarity.

## Manual/Skill boundary

The **665 skill atlas Sprite objects** are resource pictures, **not 665 manuals**. The earlier separate native count of **860 named constructor-backed Manual/Skill templates** remains unchanged. Matching those BaseIDs to Sprite names requires exact native skill/icon configuration tracing; using numeric-looking sprite filenames as BaseIDs would fabricate a join. The private browser therefore labels skill entries only as raw Sprite names with no Add Manual action.
