# Tale of Immortal Android — v1.2.4 SkillAttack BaseID → Native Icon → Unity Sprite Audit

**2026-11-03. Read-only research.** Original game APK, `classes2.dex`, `libil2cpp.so`, saves and original AssetBundles were not modified. No in-game Add Manual or Android render test was performed.

## Confirmed full constructor coverage

Exact ARM64 disassembly of the original pinned `libil2cpp.so` locates `ConfBattleSkillAttackItem` constructor at RVA `0x5d4eccc`, with **1,568** initializer callsites. This report captures the original `w1` BaseID, `x2` name-key string and `x3` icon-key string, including indirect IL2CPP metadata-string pointers and ARM64 register transfers. The conservative interpreter resolved all **1,568 unique numeric BaseIDs**; no guessed ID-based matching was used.

| Original `x2` name-key family | Constructor records |
|---|---:|
| `skill_name_middle...` | **805** |
| `chickenskillname_...` auxiliary family | **37** |
| Literal `0` placeholder | **726** |
| **All SkillAttack** | **1,568** |

The 37 auxiliary name keys are **not** automatically inventory Manuals. The **805** standard-name constructor records also must not be described as 805 complete on-screen English manual titles. The previously published **860** named constructor-backed templates spanned *three constructor families*, including Step/Ability; these are a separate baseline and must not be replaced or simply added to the 1,568 SkillAttack calls.

## Exact native icon linkage against actual Unity Sprite objects

The original `x3` icon key was joined by exact name to the two relevant UnityFS Sprite object indexes. The previously extracted `spriteatlas_commonskilliconspriteatlas.ab` has **665 real Sprite objects** with render rectangles; the additional `spriteatlas_commonstepiconspriteatlas.ab` contains **16 real Sprite objects**.

| Icon evidence | SkillAttack BaseIDs |
|---|---:|
| Exact match to Skill Sprite object + atlas render rectangle | **1,424** |
| Exact match to Step Sprite object name | **2** |
| Native icon key is literal `0` | **141** |
| Icon key not found in either selected atlas | **1** |
| **All** | **1,568** |

Thus **1,426/1,568** unique BaseIDs have an exact native icon→Sprite-name match. These 1,426 mappings reuse icons; only **434 distinct Skill Sprite icon names** are referenced by the 1,424 Skill Atlas joins. The two matches in the Step atlas are `huohu` (BaseID 7474) and `huanying` (BaseID 7484). The remaining unmatched nonzero key is `321112` (BaseID 321112). These names do not prove the item/skill is obtainable or the image has been decoded.

Of **842** nonplaceholder native name keys (805 standard + 37 auxiliary), **841** have Sprite matches in the two atlases, and **one** (`321112`) does not. The 726 native `0` name keys are explicitly kept separate from verified full manual names.

## Validation, package and limits

Private deliverables are a searchable 1,568-BaseID HTML, CSV crosswalks, separate auxiliary and placeholder distinctions, a reproducible read-only tracing script, a 16-Sprite Step-Atlas object listing, summary JSON, and a filterable spreadsheet. The ZIP was CRC checked. Source validation confirms 1,568 distinct BaseIDs, 805+37+726 name status and 1,424+2+141+1 icon status.

**Not established:** actual PNG/RGBA pixels from ASTC, manual title prefixes and English translations, Skill→Manual type grouping for all rows, displayed Grade/Realm/Rarity, native Add Manual success, DEX integration or Android gameplay tests. BaseID remains a separate namespace from normal Item ID. The 60 untranslated item names from the earlier Item catalogue also remain unresolved.

**Privacy:** The user-provided binary, save, whole extracted name/ID map, source assets, Sprite rows, and complete private package are **not** uploaded to this public repository. This public report contains methodology and aggregate counts only.
